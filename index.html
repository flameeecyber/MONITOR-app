Prometheus scrapes metrics from your services, stores them in a time-series database, and powers alerts based on query rules. It's the foundation of your monitoring stack — everything feeds into Prometheus first.

N NGINX

Reverse proxy, load balancer & web server

What It Does

NGINX sits at the front of your stack, routing traffic to the right services. It handles TLS termination, load balancing, rate limiting, caching, and serves as a reverse proxy for all your web applications.

Key Utilities

Reverse Proxy
Route traffic to backend services
Load Balancing

TLS Termination

Container runtime & orchestration

What It Does

Docker runs all your services in isolated containers. The entire monitoring stack — Grafana, Prometheus, NGINX — runs as containers managed through Docker Compose. It's the engine that powers everything.

Key Utilities

Docker Compose

Complete Stack Architecture

How everything fits together

Data Flow

NGINX → receives all HTTP traffic, proxies to backend services. Metrics exposed via stub_status endpoint.
Prometheus → scrapes NGINX metrics, node exporters, and other targets every 15s. Stores in TSDB.
Grafana → queries Prometheus (and other sources) to render dashboards. Sends alerts when thresholds breached.
Docker → all services run as containers, managed via docker-compose.yml in ~/docker/
